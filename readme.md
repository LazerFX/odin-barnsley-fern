# Barnsley Fern

Built using [odin raylib hot-reload game template](https://github.com/karl-zylinski/odin-raylib-hot-reload-game-template) as a guide.  This is a barnsley fern generator, built in Odin with Ralib.

## Build

Despite the source supporting Windows, Linux and Mac - I've only got Linux to test.  So that's what I'm targetting.
